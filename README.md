# TEM-Geophysical-Processing

瞬变电磁（Transient Electromagnetic Method, TEM）数据处理与反演研究仓库。

本仓库用于记录 TEM 数据处理、正反演、实验过程及文献学习，并逐步建立一套可复现的数据处理流程，为后续多源三维地质建模提供地下电性结构约束。

## 1. 项目目标

当前课题总体目标为综合钻孔、地球物理、地球化学、遥感等多源数据，建立三维地质模型，并分析矿体的形态与空间分布。

本仓库主要负责其中的 TEM 数据处理方向，计划逐步完成：

1. TEM 原始数据解析与质量检查；
2. 异常值、噪声及低信噪比数据处理；
3. TEM 响应可视化与基础参数分析；
4. 一维正演与反演；
5. 根据后续任务需求进一步开展二维/三维电性结构研究；
6. 将 TEM 反演结果整理为空间化电性数据，为三维地质建模及多源数据融合提供约束。

整体流程可概括为：

```text
发射电流
    ↓
一次场
    ↓
关断
    ↓
地下感应涡流
    ↓
二次场衰减
    ↓
接收线圈 → V(t) / dB/dt / B(t)
    ↓
时间道采样 + 多次叠加
    ↓
一个测点的瞬变响应数据
    ↓
多个测点 / 测线
    ↓
QC + 异常识别 + 去噪 + 校正 + 权重评估
    ↓
可靠的反演输入
    ↓
初始模型 → 正演 → 数据失配 → 正则化 → 更新 → 迭代
    ↓
ρ(z) / ρ(x,y,z)
    ↓
二维 / 三维电性结构
    ↓
与钻孔、MT、高光谱、地质资料等联合
    ↓
三维地质建模与地质解释
```

## 4. 数据管理原则

为保证科研数据安全和结果可追溯，采用以下约定：

1. `data/raw/` 中的原始数据只读保存，不直接修改；
2. 真实课题组数据未经明确允许不上传至公开 GitHub；
3. 大型公开数据集原则上不直接提交 Git，而是在 `data/README.md` 中记录来源、下载地址和数据说明；
4. 中间处理结果放入 `data/interim/`；
5. 可用于后续分析或反演的规范化数据放入 `data/processed/`；
6. 数据处理过程尽量通过代码和配置复现，避免仅通过手工操作得到不可追溯结果。

## 5. 代码与实验记录原则

后续正式实验遵循：

```text
原始数据
+ 明确的数据说明
+ 固定版本代码
+ 明确处理参数
= 可复现的处理结果
```

每次关键实验应尽量记录：

- 数据来源与版本；
- 使用的代码/Commit；
- 输入与输出文件；
- 关键参数；
- 处理方法；
- 主要结果；
- 异常与待解决问题。
